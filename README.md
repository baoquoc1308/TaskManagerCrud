# 📌 Task Manager 

A task management application built with **React, TypeScript, Supabase, Vite**.  
It supports CRUD tasks, real-time updates, pagination, and role-based dashboards.  

---

## ✨ Features
- 🔐 Authentication (email/password + social login)  
- 👤 User avatar upload & management  
- 📝 Task CRUD 
- 🔄 Real-time updates using Supabase Realtime  
- 🔍 Search & filter by keyword, priority, and date  
- 📊 Manager dashboard with task statistics  
- 🎨 Dark/Light mode support  
- 📱 Responsive design  

---

## ⚙️ Tech Stack
- **Frontend**: React, TypeScript, Ant Design  
- **Backend**: Supabase (Auth, Database, Storage, Realtime)  

---

## 📦 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. **Open your browser:**
   Visit [http://localhost:5173](http://localhost:5173) to view the app.
